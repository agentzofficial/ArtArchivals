  It was released on the 3rd of August, 2025.

  <h2 id="overview">Overview</h2>
  "the agents play all 12 games across all seasons from Squid Game. don't worry, it's just a game!"

  <h2 id="legacy">Legacy</h2>
  This episode continues a rivarly between Agent 3 and Agent X that started in [Power Outage](/about/power-outage), being a large plot point starting from the Hide and Seek game. This would continue into the next episode, [Library Thief](/about/library-thief).

  Lil' Judd being made the catalyst to this episode is also a plot element first seen it [Power Outage](/about/power-outage).

  Other agent z Content would also reference this episode:
  - [The Countdown](/about/the-countdown) sees Agent X challenge Agent 3 to a game of Rock Paper Scissors, with the loser of any given round essentially playing a round of Russian Roulette. While these aren't seen in the episode itself, aside from Neo Agent 3 playing it by herself during the Marbles game, these games are seen in Squid Game Season 2 and are a reference to that.

  <h2 id="trivia">Trivia</h2>
  - This is the first episode to be entirely based on different media, with the whole episode being based off of the Squid Game show.
  - This is the longest episode to not be officially part of a Story Arc, as well as the only non-Story Arc episode as of January 2025 to be over 20 minutes.
